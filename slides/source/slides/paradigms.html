Three computing approaches on the same 8 hardware instances (2 patients, 6–12 qubits). Classical: exact max-clique search, and simulated annealing (the classical algorithm a quantum annealer imitates). Gate-based quantum: QAOA p = 1 on IBM ibm_fez. Annealing: a linear-ramp “digitized anneal” run on the same IBM chip, which builds the annealing process out of logic gates. Each IBM run used 4,000 shots, so even a 1% hit rate finds the best answer about 40 times. A dedicated quantum annealer (D-Wave) needs paid or approved access, so it is not in this comparison; the script adds it automatically if it ever runs. Script: scripts/compare_paradigms.py.
