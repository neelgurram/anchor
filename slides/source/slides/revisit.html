Steps = two-qubit operations; clean runs = how often today’s chip (about 1 error in 300 steps, 3.3 × 10⁻³) finishes with zero errors; error rate needed = for a clean run half the time. Exact needed rates: 9.6e-3, 3.9e-3, 1.2e-3, 3.9e-4. Other conditions: the puzzle must also beat RANSAC (needs rigid-fit terms); the computer must sit in or near the hospital (our cloud queue took hours); patient data must stay within privacy rules. Per try, QAOA hit the exact best answer far less often than a normal computer (0.07% vs 79% at 16 qubits), but keeping its best try still gave the same final map. Three computing approaches on the same 8 hardware instances (2 patients, 6–12 qubits). Classical: exact max-clique search, and simulated annealing (the classical algorithm a quantum annealer imitates). Gate-based quantum: QAOA p = 1 on IBM ibm_fez. Annealing: a linear-ramp “digitized anneal” run on the same IBM chip, which builds the annealing process out of logic gates. Each IBM run used 4,000 shots, so even a 1% hit rate finds the best answer about 40 times. A dedicated quantum annealer (D-Wave) needs paid or approved access, so it is not in this comparison; the script adds it automatically if it ever runs. Script: scripts/compare_paradigms.py.
