1 · The problem

One wrong ultrasound match ruins the fix.

During surgery, doctors can take a quick, live ultrasound scan.

Find the same landmarks on the MRI and on the ultrasound, and you can measure how far each spot moved, then bend the map to match.

But ultrasound is blurry, so some matches are wrong, and one wrong match pulls the whole map out of shape.

Each purple MRI landmark has two possible blue ultrasound matches. Only one is right.

Trusting every match leaves this map 16.5 mm off. Red shows where it’s wrong.

Today’s options: ignore the shift and adjust by eye; buy an operating-room MRI (millions of dollars, few hospitals); or update the map from ultrasound, which is cheap and already in many operating rooms. Right image: same real patient as the demo (RESECT Case 12), 19.6 mm off before any fix, 16.5 mm after trusting every match. In this project the possible matches are generated around real expert-marked landmarks (the right one plus a look-alike decoy); reading real ultrasound images is not built yet. The standard way to throw out bad matches is a method called RANSAC; we compare against it in the results.
