SAY: A cheaper fix is ultrasound. We find the same spots on the MRI and on a live ultrasound, and each arrow shows how far that spot moved. But ultrasound is blurry, so some matches are wrong, like this red one. And one wrong match bends the whole map. — IF ASKED: Today’s options: ignore the shift and adjust by eye; buy an operating-room MRI (millions of dollars, few hospitals); or update the map from ultrasound, which is cheap and already in many operating rooms. Right image: same real patient as the demo (RESECT Case 12), 19.6 mm off before any fix, 16.5 mm after trusting every match. In this project the possible matches are generated around real expert-marked landmarks (the right one plus a look-alike decoy); reading real ultrasound images is not built yet. The standard way to throw out bad matches is a method called RANSAC; we compare against it in the results.
