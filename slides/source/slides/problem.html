The problem

The surgeon’s map goes out of date.

Before surgery, the patient gets a pre-operative MRI: a detailed 3D scan of the brain. In the operating room, a navigation system uses it like a GPS, showing where the surgeon’s tools are.

Once the skull is opened, fluid drains and the brain sags and shifts, by up to 2 cm. Doctors call this brain shift.

Now the map is wrong, so surgeons can leave tumour behind or cut healthy brain. The only full fix, an MRI scanner in the operating room, costs millions, and few hospitals have one.

SAY: Before surgery, the patient gets an MRI, and a navigation system uses it like a GPS for the surgeon’s tools. But once the skull is opened, the brain shifts, by up to 2 centimetres. Now the map is wrong, so the surgeon can leave tumour behind or cut healthy brain. The only full fix today is an MRI machine in the operating room, which costs millions. — IF ASKED: The pre-operative MRI is taken days before surgery; surgical navigation (like a GPS for the surgeon’s tools) lines the patient’s head up with it at the start. The shift is up to 2 cm, about 5 mm on average, from fluid loss, gravity, swelling and removed tissue. Who it affects: brain surgeons, their patients, and hospitals that can’t afford an MRI machine in the operating room (millions of dollars). How much tumour is removed is tied to survival. The 3D brain is a standard model brain for display; all measurements come from real patient data.
