SAY: We tested it on all 22 patients in a public dataset, RESECT: 264 tests, graded on landmarks Anchor never saw. Trusting every match left the map 5.6 millimetres off, worse than no fix. Anchor got it to about 2.2, on quantum and normal computers alike. A standard method, RANSAC, did slightly better, and we report that. — IF ASKED: Rubric 04. Error bars are 95% confidence intervals. Baselines: no correction 5.36 mm, naive 5.57, RANSAC 2.02, exact max clique 2.19, simulated annealing 2.19, digitized anneal 2.19, QAOA 2.17, best possible 1.78. Quantum here runs on the Aer simulator, 8–16 qubits, 20–40% wrong matches. QAOA vs exact, paired: −0.02 ± 0.06 mm, a tie. RANSAC wins by 0.17 mm because it checks a rigid fit of the whole group, which is stricter than checking pairs. Best possible with only the true matches: 1.78 mm.
