1 · The problem

Ultrasound can show where it moved.

During surgery, doctors can take a quick, live ultrasound scan.

If you find the same landmarks on the MRI and on the ultrasound, you can measure how far each spot moved.

But ultrasound is blurry, so some matches point to the wrong spot.

Each purple MRI landmark has two possible blue ultrasound matches, and only one is right.

Today’s options: ignore the shift and adjust by eye; buy an operating-room MRI (millions of dollars, few hospitals); or update the map from ultrasound. Ultrasound is cheap and already in many operating rooms. In this project the possible matches are generated around real expert-marked landmarks (the right one plus a look-alike decoy); reading real ultrasound images is not built yet.
